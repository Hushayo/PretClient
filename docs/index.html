Install in 60 seconds

  1. Download the setup exe above.
  2. Run it — no admin, pick Start Menu / Desktop icons, click Install.
  3. Play — set a username, create a Vanilla or Fabric instance, hit Play. Add Modrinth mods per instance.

Updating? Just accept the in-app update prompt — it downloads the new setup, runs it silently, and relaunches. Or re-run the installer manually; settings and instances are kept.

FAQ

Is it offline / premium auth?

Offline play with username profiles. No Microsoft login — perfect for testing, modpacks, and LAN worlds.

Where are my files?

Settings → game folder (default under your data dir), with instances/<id> and instances/<id>/mods per instance, plus settings.json.

How do updates work?

The app polls GitHub Releases, compares against its stamped VERSION, and offers one-click PretClient-Setup.exe download + install.

Build from source?

Don't build locally — push to CI per workflow.md: msbuild PretClient.sln /restore /p:Configuration=Release /p:Platform=x64 runs on windows-2022. Test builds come from Actions artifacts or Releases.
