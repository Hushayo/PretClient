Winget, honestly

There is no winget install PretClient and there never was. Here is where the real package stands.

  1. Manifests are in this repo Ready

    They live under winget/manifests/h/hushayo/pretclient/<version>/ with a version-pinned URL and SHA256, InstallerType: inno, Scope: user and the silent flags /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-.

  2. The first publish is manual Not done yet

    Copy that folder into a microsoft/winget-pkgs fork at manifests/h/hushayo/pretclient/<version>/, run winget validate --manifest, then open the PR. It is needed once, because winget-releaser needs a base version to update from.

  3. After the merge, updates are automatic After step 2

    This repo's winget.yml watches releases and opens update PRs through vedantmgoyal9/winget-releaser. It needs a WINGET_TOKEN repo secret (classic PAT with public_repo and workflow) and a winget-pkgs fork under the same owner.

Test the manifest locally today 
winget settings --enable LocalManifestFiles
winget validate --manifest .\winget\manifests\h\hushayo\pretclient\2.0.12\Hushayo.PretClient.yaml
winget install --manifest .\winget\manifests\h\hushayo\pretclient\2.0.12\Hushayo.PretClient.yaml

# after the winget-pkgs PR merges:
winget install Hushayo.PretClient
winget upgrade Hushayo.PretClient

Why isn't it live? Nobody has submitted the first version, and the automation can't create it. Do step 2 once and never again.

FAQ

Why did winget install PretClient fail?

That ID was never published. Use winget install Hushayo.PretClient after the winget-pkgs PR merges, or the --manifest path above until then.

What are the silent install flags?

PretClient-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-. These are the same flags winget uses.

Where are my files?

In the game folder you pick in Settings. Each instance gets instances/<id> and instances/<id>/mods, and preferences are in settings.json.

How do updates work?

In the app, it polls GitHub Releases, downloads the new setup with one click and reinstalls silently. Through winget, use winget upgrade Hushayo.PretClient once the package is published.
