Winget, honestly.

The old page claimed winget install PretClient — that package doesn't exist yet. Here's the real path:

  1. Manifests live in this repo under winget/manifests/h/hushayo/pretclient/<version>/ — version-pinned URL + SHA256, InstallerType: inno, Scope: user, silent flags /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-.
  2. First publish is manual. Copy that folder into a microsoft/winget-pkgs fork at manifests/h/hushayo/pretclient/<version>/, run winget validate --manifest, open the PR. Required once — winget-releaser needs a base version to update from.
  3. After merge, it's automatic. This repo's winget.yml watches releases and opens update PRs via vedantmgoyal9/winget-releaser. Needs a repo secret WINGET_TOKEN (classic PAT: public_repo + workflow) and a winget-pkgs fork under the same owner.
winget — test locally today
winget settings --enable LocalManifestFiles
winget validate --manifest .\winget\manifests\h\hushayo\pretclient\2.0.12\Hushayo.PretClient.yaml
winget install --manifest .\winget\manifests\h\hushayo\pretclient\2.0.12\Hushayo.PretClient.yaml

# after the winget-pkgs PR merges:
winget install Hushayo.PretClient
winget upgrade Hushayo.PretClient

Why not merged yet? Nobody submitted it. The automation can't create the very first version — do step 2 once, then never again.

FAQ

Why did winget install PretClient fail?

That ID was never published. Use winget install Hushayo.PretClient after the winget-pkgs PR merges — or the --manifest path above until then.

Silent install flags?

PretClient-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- — same flags winget uses.

Where are my files?

Game folder from Settings, instances/<id> + instances/<id>/mods per instance, settings.json for prefs.

How do updates work?

In-app: polls GitHub Releases, one-click setup download + silent reinstall. Winget: winget upgrade Hushayo.PretClient once published.
