A small Minecraft launcher for Windows.

It installs for your user only, with no admin prompt and no account. Make Vanilla, Fabric, Quilt, Forge or NeoForge instances, add mods from Modrinth, and watch CPU, RAM and the game log on the card while the game runs.

Download for Windows All releases

Windows 10 (1809 or later) and 11, x64. Free and open source under GPL-3.0.

What it does

No store, no news feed, no sign-in. This is the whole list.

Instances
Vanilla, Fabric, Quilt, Forge or NeoForge, each in its own folder. Play offline with a username profile. While an instance runs, its card shows CPU, RAM, GPU and the end of the game log. Idle cards just say Ready to play.
Mods
Search Modrinth without leaving the launcher. Mods install into that instance's mods/ folder, locked to its version, with a one-click install and an update check.
Settings
Pick the game folder, let Java auto-detect or point to your own, and set minimum and maximum memory (512 MB and 2048 MB by default). Everything is saved in settings.json.
Updates
The launcher checks GitHub Releases. One click downloads the new setup, installs it silently and relaunches.
Footprint
An unpackaged WinUI 3 C++ exe, installed per user with Inno Setup into %LocalAppData%\Programs\PretClient. No MSIX, no admin.
Source
GPL-3.0. CI builds on windows-2022: every push to main is built and every tag ships a release. Read the code on GitHub.

Winget

winget install PretClient does not work and never did. The package ID is Hushayo.PretClient, and it is not in the winget-pkgs repository yet.

  1. Manifests are in this repo Ready

    They live under winget/manifests/h/hushayo/pretclient/<version>/ with a version-pinned URL and SHA256, InstallerType: inno, Scope: user and the silent flags /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-.

  2. The first publish is manual Not done yet

    Copy that folder into a microsoft/winget-pkgs fork at manifests/h/hushayo/pretclient/<version>/, run winget validate --manifest, then open the PR. It is needed once, because winget-releaser needs a base version to update from.

  3. After the merge, updates are automatic After step 2

    This repo's winget.yml watches releases and opens update PRs through vedantmgoyal9/winget-releaser. It needs a WINGET_TOKEN repo secret (a classic PAT with public_repo and workflow) and a winget-pkgs fork under the same owner.

FAQ

Why did winget install PretClient fail?

That ID was never published. Use winget install Hushayo.PretClient after the winget-pkgs PR merges, or the --manifest route above until then.

What are the silent install flags?

PretClient-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-. These are the same flags winget uses.

Where are my files?

In the game folder you pick in Settings. Each instance gets instances/<id> and instances/<id>/mods, and your preferences are in settings.json.

How do updates work?

In the app, it checks GitHub Releases, downloads the new setup with one click and reinstalls silently. Through winget, use winget upgrade Hushayo.PretClient once the package is published.
